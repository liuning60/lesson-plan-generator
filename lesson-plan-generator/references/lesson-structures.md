# Lesson Plan Structures (lesson-structures)

Pick the structure by level (university / secondary) and mode (whole book / single session). Whole book = cover + course info table + N session tables; single session = one session table.

## University Plans (incl. higher/secondary vocational) — Whole Book

Standard higher-education lesson-plan book structure:

### Cover
| Field |
|---|
| School name |
| "Lesson Plan" |
| Academic year & semester (e.g. 2026–2027, Semester 1) |
| Department / teaching-research office |
| Instructor |
| Course name |
| Program / major |
| Class(es) |
| Footer (e.g. "Issued by XXX College Academic Affairs Office") |

### Course Info Table
| Field |
|---|
| Course name / course code / course type (core/elective) |
| Audience (undergraduate/vocational etc.), major-grade-class |
| Instructor, title |
| Course teaching objectives |
| Key points & difficulties |
| Main teaching methods & tools (lecture/discussion/case/lab/experiment etc.) |
| Textbook |
| Main references |

### Per-Session Table (one per session, numbered by hours/week)
| Column |
|---|
| Session time (session N, week, period) |
| Hours |
| Teaching mode (theory/discussion/exercises/experiment/lab/skills etc., tick) |
| Session title (chapter-section-knowledge point) |
| Objectives & requirements |
| Key points & difficulties |
| **Time arrangement (required row)** |
| Teaching content: teaching process (incl. six-element cases), case steps, assessment ｜ Methods & tools |
| Summary / post-class summary |
| Questions / homework / references |

### Assembly Rules
- Whole-book mode generates N session tables by total hours (or weeks), numbered continuously, hours summing to the total.
- Session titles expand as "chapter-section-knowledge point", aligned with the course info table's objectives.
- Session duration = hours × 45 min (e.g. 4 hours = 180 min); time-arrangement phase minutes must sum to that total.

## Time Arrangement (Required)

- Add a **"time arrangement"** line to every session table listing phases with minutes: introduction, lecture, demo, student practice, roving coaching, summary & comments.
- **Lab/practice phases must split into "student independent practice X min" + "teacher roving coaching X min"**.
- All phase minutes sum to the session total. **Budget first, then write content** — never under-fill or overflow.
- Example: "【Time arrangement】Intro 10′｜Lecture 40′｜Demo 15′｜Lab: independent practice 45′ + roving coaching 15′｜Summary 25′｜Total 180′"

## Teaching-Process Formatting Rules (fixes "content crammed together"; required)

Production lesson: content stacked in a single paragraph is unreadable; use "headings on their own lines + content split into lines":

1. **【Time arrangement】bold on its own line**, with each phase on its own line below (Intro 10′ / Lecture 40′ / … / Total 180′).
2. **Phase titles bold on their own line** (e.g. "Phase 2 Overview & Industry Awareness (40′)"), content items "① ② ③ ④" each on their own line.
3. **Case name bold on its own line** ("Case 1 (six elements) · case name"); six elements as separate blocks — bold labels 【Background】【Relation to objectives】【Implementation process】【Results & data】【Teaching comment】【Questions】 each on its own line, content lines below (steps/questions ① ② ③ each on its own line).
4. **Lab/practice**: "Task — …" and "Student independent practice 45′, teacher roving coaching 15′" on separate lines.
5. **Assessment** items each on their own line.
6. Line spacing 1.15; title lines space-before 8-12pt, title lines space-after 3-4pt.
7. Image zone separated from body: space before each image (10pt), space after captions (14pt); every image gets a caption "Fig N ｜ title ｜ source".
